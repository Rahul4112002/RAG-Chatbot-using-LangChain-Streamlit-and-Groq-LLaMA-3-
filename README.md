# 🤖 RAG Chatbot with LangChain, Streamlit, and Groq
![image](https://github.com/user-attachments/assets/90a9b626-3c55-4157-aec5-7667dc42467f)

A smart chatbot application that combines **LLMs (LLaMA 3 by Groq)** with **retrieval-based PDF question answering**. Users can ask natural questions about the content of a PDF document, and the system responds with context-aware, accurate answers.

## 🚀 Features

- 🔍 Ask questions directly from a PDF file (`rahul.pdf`)
- ⚡ Super-fast responses using Groq's LLaMA 3 model (`llama3-8b-8192`)
- 🧠 Embedded PDF content via HuggingFace Embeddings
- 🧱 Built with LangChain's RetrievalQA + VectorstoreIndex
- 🖥️ User-friendly Streamlit web interface
